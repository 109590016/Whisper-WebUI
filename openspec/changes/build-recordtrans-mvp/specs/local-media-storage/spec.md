# Spec Delta

## Purpose

確保錄音與上傳媒體在本機被可靠保存、可追溯，且不因瀏覽器重新整理、暫存清除或容器重建而遺失。

## ADDED Requirements

### Requirement: 可設定的永久資料目錄
系統 MUST 將來源、輸出與狀態保存於啟動時設定且通過可寫檢查的資料目錄。

#### Scenario: 有效資料目錄
- **WHEN** 系統以可寫資料目錄啟動
- **THEN** 系統建立必要子目錄並允許錄音與上傳

#### Scenario: 無效資料目錄
- **WHEN** 資料目錄不存在且無法建立或不可寫
- **THEN** 系統阻止建立來源並顯示可採取行動的錯誤

### Requirement: 永久保存來源
系統 SHALL 在接受轉錄前，以唯一識別碼永久保存錄音或上傳來源，且相同檔名不得互相覆蓋。

#### Scenario: 保存同名來源
- **WHEN** 使用者先後提交兩個同名檔案
- **THEN** 系統建立兩筆不同來源並保留各自內容

#### Scenario: 保存未完成
- **WHEN** 來源寫入中斷或失敗
- **THEN** 系統不得將該來源標記為可轉錄的完整來源

### Requirement: 重啟後資料可用
系統 MUST 在容器重建或服務重啟後，仍能依記錄找到已保存來源與已完成輸出。

#### Scenario: 容器重建
- **WHEN** 使用者以相同資料目錄重建並啟動容器
- **THEN** 已保存來源、結果與任務紀錄仍可查詢
